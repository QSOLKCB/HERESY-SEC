# Geometry holonomy

This ordered stream is classically allowed action by action, but the two actions
return to the same resource under incompatible authority masks. The
`heresy-geom.profile/v1` holonomy gate produces `delta_P = 1`, registers a
`PRIVILEGE_PENROSE_LOOP`, disarms Shadow Guard and makes the final state `DENIED`.

```sh
python -m heresy_sec monitor examples/geometry_holonomy/events.jsonl \
  --policy examples/geometry_holonomy/policy.json \
  --runs-dir runs \
  --run-name geometry-holonomy
python -m heresy_sec inspect runs/geometry-holonomy
python -m heresy_sec replay runs/geometry-holonomy
```

The actions are descriptions only. The example neither reads nor writes the named
file.
