# Roadmap

## v0.1.x — deterministic nucleus

- stabilize schemas and golden vectors;
- add property-based fuzz corpora without adding runtime dependencies;
- benchmark streams of at least 17,000 synthetic events;
- expand path, URL, policy-conflict and tamper tests;
- publish deterministic example archives.

## v0.2.x — deterministic geometry profile

- maintain `heresy-geom.profile/v1` action graphs and integer geometry;
- expand path/cycle spectral fixtures within the bounded window contract;
- add independent cross-language vectors for graph and receipt identities;
- seek clarification of the academic paper's missing T9/T10 definitions;
- treat any author feedback as a versioned compatibility decision, not a silent
  semantic change.

## v0.3.x — adapters and exchange

- bounded streaming capture protocol;
- QSOLAI capture adapter;
- common agent-trace importers;
- SARIF 2.1.0 decision and geometry-witness export;
- cross-language classical and geometry conformance vectors.

## v0.4.x — authenticated provenance

- SPIFFE-compatible workload identity validation;
- in-toto/Sigstore-compatible detached attestations;
- explicit signer and approval receipts;
- transparent key and revocation policy.

## v0.5.x — multi-model forensics

- competing open/closed model findings after exact capture;
- deterministic adjudication with unresolved disagreement preserved;
- reproducible incident-evaluation corpus;
- optional SPECTRAL alert sonification from already committed decisions.

The v0.2 geometry implementation is described in
[HERESY-GEOM status](HERESY_GEOM.md) and the normative
[`heresy-geom.profile/v1`](HERESY_GEOM_PROFILE.md). Future geometry work must remain
bounded, integer/rational, versioned and incapable of weakening classical policy.

See [Open Secure AI Alliance contribution path](OPEN_SECURE_AI_ALLIANCE.md) for the
external interoperability goal. Version numbers express intent, not guarantees.
