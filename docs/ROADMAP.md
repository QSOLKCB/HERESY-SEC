# Roadmap

## v0.1.x — deterministic nucleus

- stabilize schemas and golden vectors;
- add property-based fuzz corpora without adding runtime dependencies;
- benchmark streams of at least 17,000 synthetic events;
- expand path, URL, policy-conflict and tamper tests;
- publish deterministic example archives.

## v0.2.x — adapters and exchange

- bounded streaming capture protocol;
- QSOLAI capture adapter;
- common agent-trace importers;
- SARIF 2.1.0 decision export;
- cross-language conformance vectors.

## v0.3.x — authenticated provenance

- SPIFFE-compatible workload identity validation;
- in-toto/Sigstore-compatible detached attestations;
- explicit signer and approval receipts;
- transparent key and revocation policy.

## v0.4.x — multi-model forensics

- competing open/closed model findings after exact capture;
- deterministic adjudication with unresolved disagreement preserved;
- reproducible incident-evaluation corpus;
- optional SPECTRAL alert sonification from committed decisions.

## v0.5.x — falsifiable geometric extension

This track is contingent on receipt of the complete independently authored
HERESY-GEOM specification and conformance vectors.

- canonical ordered action-graph contract;
- integer or explicitly rational discrete-curvature representation;
- holonomy-gate evidence that can tighten, but never bypass, hard boundaries;
- shadow-guard integrity receipts committed to the existing manifest;
- atom-addressable policy-object identities;
- impossible-configuration registry with deterministic witnesses;
- KR-MPGM spine semantics and falsification tests.

See [HERESY-GEOM integration notes](HERESY_GEOM.md). The names above describe a
prospective extension boundary, not features currently implemented by HERESY-SEC.

See [Open Secure AI Alliance contribution path](OPEN_SECURE_AI_ALLIANCE.md) for the
external interoperability goal. Version numbers express intent, not guarantees.
